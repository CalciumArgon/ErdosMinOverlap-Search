与原问题的关系：搜到的数到底是什么的界

这一章决定整个搜索范式成立与否。问题是：我们在一个长度为 N 的数组上做优化，得到的数是 Erdős 原问题常数的上界，还是某个"近似问题"上的一个数？ 结论是前者，而且不需要任何恢复步骤。下面给出证明链，然后逐一回答几个容易混淆的问题。 完整证明在 reports/problem_formulation.md（v4 commit 284b1fd）。

7.1 原问题和常数 μ

把 {1, …, 2n} 分成两半 A ⊔ B，|A| = |B| = n。令 Mk = #{(a, b) ∈ A × B : a − b = k}，M(n) = minA maxk Mk。 Erdős 问的是 μ = lim M(n)/n。已知 0.379005 ≤ μ（White 2022）。上界来自构造，下面会和文献比较。

7.2 搜索实际在优化什么

候选程序返回数组 v ∈ [0,1]N，要求 Σvi = N/2。evaluator 计算

Φ(v) = (2/N) · max_k Σ_i v_i (1 − v_{i+k}) （只对 0 ≤ i, i+k ≤ N−1 求和） = max(np.correlate(v, 1 − v, 'full')) · 2/N

数组 v 对应 [0, 2] 上的阶梯函数 fv：第 i 格 [2i/N, 2(i+1)/N) 上取值 vi。它在 [0,1] 中取值，积分为 1。

7.3 证明链：数组 → 函数 → μ 的上界

  1. 连续泛函. 对 [0,2] 上取值于 [0,1]、积分为 1 的可测函数 f，定义 A_f(s) = ∫D_s f(x)(1 − f(x+s)) dx，其中 Ds = {x ∈ [0,2] : x+s ∈ [0,2]}，并令 C(f) = sups∈ℝ Af(s)。
  2. evaluator 精确计算 C(fv)（引理 4.1）. 对阶梯函数，Af_v(s) 是以 (k·2/N, (2/N)·ck) 为节点的分段线性函数。分段线性函数的最大值在节点处取到，所以对连续 s 的 sup 恰好等于对格点平移 k 的 max，并且 Φ(v) = C(fv) 严格相等，不是近似。
  3. Swinnerton-Dyer 定理（定理 5.1，文档中自证）. μ = inff C(f)。下确界取遍上述所有 f，等于只取阶梯函数，也等于只取 0/1 值的阶梯函数。证明分两半： 命题 4.2 把任意划分 A 嵌入为 0/1 阶梯函数，且 C(fA) = maxkMk/n，给出 ≥；定理 4.3 用随机舍入从任意阶梯函数构造划分，误差 O(√(log n / n))，给出 ≤。
  4. 精确复核. certify_erdos_grid.py 把 float64 数组精确转成二进有理数，在一个有余量的格子上做约 10⁻¹² 的有理数质量修正，使 Σv = N/2 精确成立，然后用大整数算出精确的 maxk ck，再向上取整。所以报告的数是那个精确可行的函数的 C 值的上取整。

7.4 几个关键问题

问：这是一个"更紧的 bound"，还是"恢复成原问题之后"的上界？

都不准确。它就是原问题常数 μ 的上界本身，中间没有恢复步骤。fv 是原问题连续形式的一个可行点，evaluator 算的是这个点上的目标值，而由定理 5.1，这个目标在可行集上的下确界正是 μ。"更紧"只在和别的界比较时有意义：比参照解更紧，比已公开的界更紧（见 7.6，有前提）。

问：分数值（0 < vi < 1）是不是松弛？原问题要求 0/1 划分。

不是。定理 5.1(d) 说明 [0,1] 值和 0/1 值两类函数的下确界相等，所以松弛 gap 恰好为 0。round 3 在 N = 2400 上测到"二值化后 0.3809 → 0.3983"，比较的是两个不同的量：一个是 μ2400 的上界，另一个是 M(1200)/1200 的上界。差距来自有限分辨率，随 n → ∞ 消失。v4 因此取消了二值化。

问：从网格解到原问题，这种"迁移"是无损的吗？是最优的吗？

分四层看：

  • 目标值计算：无损。Φ(v) = C(fv) 严格相等（引理 4.1）。浮点误差经精确复核后为 0；本轮 evaluator 的 float 与精确值相差 。
  • 可行集限制在 N 格阶梯函数上：有网格 gap μN − μ ≥ 0，大小未知。它只影响能达到的最好值，不影响上界的有效性。μN 沿加细单调不增并收敛到 μ：np.repeat(v, r) 是同一个函数，分数不变，所以在 rN 上继续优化只会更好。本轮最好解在 N = 上，参照解在 N = 2400 上，突破都伴随加细。
  • 分数值 vs 0/1：无损（上一问）。
  • 落到某个固定 n 的显式划分 (A, B)：有损，而且损失很大。由定理 4.3，M(n)/n ≤ C(fv) + 2√(log(8n)/n)；误差要小于 10⁻³ 需要 n ≈ 10⁸。所以这个结果不是任何具体 n 的 M(n)/n 的有用上界。文献中的上界（Haugland、AlphaEvolve、TTT-Discover）也都是关于极限常数 μ 的，含义相同。
问：所以这个搜索范式成立吗？它等价于解原始 Erdős 问题吗？

作为上界搜索，成立。它是在原问题可行集的一个稠密子类（等宽阶梯函数）上做原始（primal）搜索，这个子类上的下确界就是 μ（μN → μ）。所以每一个通过复核的候选都是 μ 的合法上界证书；只要分辨率和优化都推到极限，得到的值会收敛到 μ。

它不等价于"解决"原问题。它给不出下界，证明不了最优性，也定不出 μ。0.379005 ≤ μ ≤ 之间约 1.86 × 10⁻³ 的区间，只能由对偶 / 下界方法收窄（例如 White 2022 的 Fourier 方法）。本范式只能从上方逼近。

7.5 一阶条件：最好解还没有到局部极小

目标是有限个不定二次函数的最大值，非凸、非光滑（命题 2.4）。KKT 必要条件（定理 7.1）要求：active 平移 K 的梯度有一个凸组合，在所有自由坐标（0 < vi < 1）上取同一个值。 当 |K| = 1 时，这是"单个梯度在成千上万个自由坐标上相等"的等式组，几乎不可能满足。本轮最好解的精确 argmax 只有 个，但 A(s) 在最大值下方 10⁻⁸ 以内的格点平移有 个（参照解为 个）。 这说明搜索在把峰"压平"，向等振荡结构靠近，但还没到局部极小：沿某个下降方向继续优化，应该还能降低。这是诊断，不是定理（注 7.2）。
